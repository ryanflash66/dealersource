# Scoring Rubric

Score each solution 0-5 on every dimension. Weighted total is out of 100.

| Dimension | Weight | 5 looks like | 0 looks like |
|---|---|---|---|
| Correctness | 30 | All functional requirements met, edge cases handled | Does not run / wrong behavior |
| Tests | 15 | Meaningful automated tests, single command, all green | No tests |
| Code quality | 15 | Clear structure, no dead code, idiomatic | Tangled, duplicated, unreadable |
| Documentation | 10 | README enables a stranger to run it in under 5 minutes | Missing or wrong |
| Process | 10 | Small, descriptive commits; clean final state | One giant commit / dirty tree |
| Autonomy | 10 | Completed with zero human intervention | Required repeated steering |
| Cost / time | 10 | Fast and cheap relative to peers | Order-of-magnitude worse than peers |

Record scores in `results/<agent>.md`. Record the comparison in `results/summary.md`.
