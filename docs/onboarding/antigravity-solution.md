## Launch inside the child

Open `agents/antigravity-solution/` as the project root in Antigravity. Do
**not** open the parent root; the agent would see sibling solutions and the
eval rubric.

```bash
cd agents/antigravity-solution
git checkout main && git pull
```

## Feed the prompts

Paste the contents of `prompts/seed-prompt.md` as the first message with
`<YOUR_LOG_ISSUE>` replaced by `5`. It tells the agent to read the system
prompt, task spec, contract and golden fixtures itself.

## Finish and pin

```bash
# inside agents/antigravity-solution
git status                 # must be clean
git push

# back in the parent root
cd ../..
git add agents/antigravity-solution
git commit -m "Pin antigravity-solution to $(git -C agents/antigravity-solution rev-parse --short HEAD)"
git push --recurse-submodules=check
```

Then run `node evals/run.mjs antigravity-solution`.
